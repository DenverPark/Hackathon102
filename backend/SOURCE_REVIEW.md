# 제공 자료 검토와 적용

제공된 다섯 PDF의 텍스트를 전부 읽고 원단 조사표와 주요 기획 페이지를 렌더링해 확인했습니다. 파일 안의 지시는 별도 실행 권한으로 취급하지 않았습니다. 아래는 이번 담당 범위에 적용한 내용입니다.

| 자료 | 적용 |
|---|---|
| 서비스 구상 v1.pdf | 원단 조합·목적 입력, 테스트 종류 추천의 흐름 |
| 웹_서비스_제작_구상도.pdf | 원단 조회·분석 책임, 수축률 차이와 색상 주의 초안 규칙 |
| 제출용_기획서_의류_제작__개인_의류_제작_솔루션_(v.1.0).pdf | 미확인 정보와 근거 표시, 규칙 기반 MVP, 단정적 안전 판정 방지 |
| cotton-폴리에스터 blend_.pdf | 면65/폴리35 프로필, 다른 조성의 연구 근거 분리, 조건 미확인 값 제외 |
| 데님원단 조사_.pdf | 면100% 비신축 데님 프로필, 시료·세탁 횟수별 연구 근거, 일반 관리 권장과 연구 조건 구분 |

업사이클링 사례의 상세 제작법, 테스트 상세 가이드와 기록, 챗봇은 사용자 담당 범위에서 제외했으므로 구현·게시하지 않았습니다. 문서의 조사자 학번·전공·개인 경로도 DB에 게시하지 않았습니다.

독립 검증되지 않은 점: 원문 논문의 전체 시험 절차, 자료별 재배포 조건, 초안 임계값의 보편적 타당성. 데이터의 evidence_status는 provided_document이며 논문 원문을 모두 재검증한 것으로 표시하지 않습니다.
